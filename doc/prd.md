# 할 일 관리 앱 PRD

Nov 23, 2026 · @Daehwan

## 1. why - 목적

- 일일 할 일, 주간 계획, 1년 목표를 하나의 구조로 연결
- 할 일 상태가 바뀌면 주간 진행률과 연간 목표 진행 상황에 자동 반영
- 드래그 앤 드롭으로 상태를 바로 바꿔 관리 부담 감소

## 2. who - 타깃 사용자

- 1년 단위 목표를 세우고 주 단위로 실행을 관리하는 개인 사용자
- 할 일 진행 상태(todo/doing/done)를 칸반 방식으로 보고 싶은 사용자
- 오늘 하는 일이 장기 목표와 어떻게 이어지는지 확인하고 싶은 사용자

## 3. User Flow

1. 1년 목표 생성
2. 주간 계획 생성 → 1년 목표 1개에 연결
3. 할 일 생성 → 날짜 지정, 주간 계획 1개에 연결
4. 일일 보드에서 할 일 확인 (todo / doing / done 컬럼)
5. 할 일 카드를 드래그 앤 드롭해 상태 변경
6. 주간 진행률 자동 재계산 및 표시
7. 1년 목표 화면에서 연결된 주간 계획의 진행 상황 확인
8. 할 일 수정/삭제 → 진행률 자동 재계산

## 4. 기능 요구 사항

### P0 - 핵심 기능

- **할 일 CRUD**
  - 생성: 제목(필수), 날짜(필수), 연결 주간 계획(선택), 상태(기본값 todo)
  - 수정: 제목, 날짜, 상태, 연결 주간 계획
  - 삭제: 삭제 전 확인, 삭제 후 진행률 재계산
- **상태 관리**
  - 상태값: `todo` / `doing` / `done`
  - 한 할 일은 한 번에 상태 하나만 가짐
- **드래그 앤 드롭 상태 변경**
  - 보드 컬럼: todo / doing / done
  - 카드를 다른 컬럼으로 옮기면 상태 즉시 변경 및 저장
  - 저장 실패 시 원래 위치로 롤백하고 오류 표시
- **기간 구조**
  - 일일: 날짜별 할 일 목록 및 보드
  - 주간: 주간 계획 CRUD (제목, 시작일\~종료일, 연결 1년 목표)
  - 1년 목표: 목표 CRUD (제목, 연도)
- **구조 연결**
  - 연결 방향: 할 일(N) → 주간 계획(1), 주간 계획(N) → 1년 목표(1)
  - 상위 항목 삭제 시 하위 항목의 연결 해제 (하위 데이터는 유지)
  - 각 화면에서 상위/하위 연결 항목 조회
- **주간 진행률 자동 반영**
  - 계산식: 연결된 할 일 중 `done` 개수 ÷ 연결된 할 일 전체 개수 × 100
  - 재계산 시점: 할 일 생성/수정/삭제/상태 변경 시
  - 연결된 할 일이 0개면 0% 표시
  - 주간 계획 화면에 진행률 바와 수치(%) 표시

### P1 - 추가 기능

- 1년 목표 진행률: 연결된 주간 계획 진행률의 평균
- 할 일 필터: 상태별, 주간 계획별
- 같은 컬럼 안에서 드래그로 순서 변경
- 미완료 할 일을 다음 날짜로 이월
- 주간 진행률 히스토리 (주차별 추이)
